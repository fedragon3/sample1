# 나를 알아보는 시간 — 성격검사(TCI) + 사주팔자

브라우저에서 **링크만 있으면 누구나** 바로 쓰는 자가탐색 웹앱입니다. 메인 메뉴에서 두 기능을 고를 수 있습니다.

1. **기질·성격 검사** — Cloninger의 TCI 7차원 이론 기반 성격 자가탐색
2. **사주팔자·운세** — 생년월일시로 사주 8자·오행·운세를 계산 (재미·오락용)

설치·로그인·서버 없이 동작하며, 입력·응답은 어디에도 전송되지 않습니다.

## 성격검사(TCI) 특징

- **완전 정적 · 서버 불필요** — HTML/CSS/JS 순수 구현, 외부 라이브러리 0개
- **개인정보 미수집** — 모든 응답은 사용자 브라우저에서만 처리되며 어디에도 전송되지 않습니다
- **7차원 · 28하위척도 분석** — 자극추구 · 위험회피 · 사회적 민감성 · 인내력 · 자율성 · 연대감 · 자기초월
- **간단(28문항) / 심화(140문항) 두 가지 모드**
- **응답 편향 보정** — 차원별 정방향/역방향 문항을 10:10(간단 14:14)으로 균형 있게 배치해,
  한쪽으로만 응답하면 모든 점수가 50%로 수렴하도록 설계(묵종 편향 완화)
- **레이더 차트 결과** + 차원·하위척도별 해석 및 상·하위 특성 요약
- **응답 신뢰도 참고 지표** — 주의(함정) 문항, 직선응답·'보통' 과다 감지, (심화)
  상반 문항 간 내적 일관성으로 성의 없는 응답을 "양호/주의"로 표시(임상 타당성
  척도가 아닌 품질 휴리스틱)
- **문항 순서 무작위화** — 매 검사마다 순서를 섞어 순서 효과를 완화(시드 기반)
- **링크로 결과 공유** — 모드·순서 시드·응답이 URL 해시에 인코딩되어, 링크만으로
  같은 순서·같은 결과를 그대로 재현
- **라이트/다크 모드** 자동 대응, 모바일 반응형

## 사주팔자·운세 특징

- **DB 없이 계산** — 사주는 저장이 아니라 계산. 60갑자 순환 + 태양 황경(절기)으로 4기둥을 산출
  - 일주(日柱): 율리우스 적일수 기반 `(JDN + 49) mod 60` (2000-01-01=무오로 검증)
  - 연·월주: 태양 황경으로 입춘·12절 경계 판정, 오호둔 규칙
  - 시주(時柱): 일간 + 2시간 단위 지지, 오자둔 규칙
- **결과 표시** — 사주 8자(오행 색상·한자), 오행 분포, 일간·오행 기반 운세 6종
  (기질/오행균형/애정/재물·직업/건강/총운) — 모두 규칙 기반으로 직접 작성한 원본 텍스트
- **양력 입력**(1900~2100), 한국 표준시 시계시각 기준. 시간 모름 선택 가능
- **링크로 결과 재현** — 생년월일시가 URL 해시에 인코딩
- 재미·오락 및 자기이해용 (전문 명리 상담 대체 아님)

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 메인 메뉴 · 두 기능의 화면 구조 및 스타일 |
| `app.js` | 성격검사 진행·채점·차트 + 사주 입력·결과 렌더 + 라우팅 |
| `questions.js` | TCI 140문항 · 7차원 · 28하위척도 정의 |
| `saju.js` | 사주 계산 엔진(절기·60갑자) 및 운세 해석 텍스트 |

## 로컬에서 실행

브라우저로 `index.html`을 여는 것만으로 동작합니다. (또는 간단한 정적 서버)

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 온라인 배포 (GitHub Pages)

`master`/`main` 브랜치에 푸시하면 `.github/workflows/deploy.yml`이 자동으로 GitHub Pages에 배포합니다.
저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 설정하면 됩니다.
배포 후 발급되는 링크를 공유하면 누구나 접속할 수 있습니다.

## ⚠️ 안내

본 검사는 교육 및 자기이해를 위한 **비공식 자가탐색 도구**입니다.
정식 TCI 검사의 저작권 문항이 아니라, 공개된 7차원 이론을 바탕으로 **독자적으로 작성한 문항**을 사용합니다.
심리 상담이나 임상적 진단을 대체하지 않습니다.
